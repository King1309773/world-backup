# World Backup 更新日志

## 1.0.1 — 2026-10-17

本次为 Minecraft 1.12.2 Forge 单人世界备份的保守性能更新。配置、默认值、备份格式与恢复流程保持兼容。

- 减少快照阶段重复的真实路径解析和目标文件属性查询，保留路径、文件身份及内容一致性检查。
- 使用最多 8 MiB 的可取消传输块；遇到零进展时回退到有界缓冲复制，保留修改时间及已有目标不覆盖保护。
- 日志新增保存/刷新、快照扫描与复制、恢复保存、清理和后台归档的分阶段耗时；聊天栏仍显示总耗时。
- 增加内容、时间戳、NTFS junction 拒绝、复制中目录替换、取消清理、短传输及零进展回退测试；修正已有维护测试的等待时序。

同一批模拟文件交替对比：8192 个小文件（128 MiB）快照中位耗时从 23.07 秒降至 14.33 秒，约减少 38%；混合文件（544 MiB）从 6.28 秒降至 4.63 秒，约减少 26%。仅三轮样本，缓存与后台扫描未隔离；大文件收益不确定，不能据此保证实际游戏完整停顿或 FPS 改善。复制阶段仍暂停世界。

自动验证：307 项测试，0 失败、0 错误、1 项 Windows 平台条件跳过。1.0.1 已本地安装，但发布前未完成真实客户端游玩验证；重要存档请另存一份备份。

完整基准与边界见 [性能报告](https://github.com/King1309773/world-backup/blob/v1.0.1/docs/performance/2026-10-16-snapshot-results.md)。1.0.0 旧版发布保留用于回退。
